👥 Play with a Friend — real 1v1, two devices

Create a room and you get a 4-letter code. Your friend opens this same game link on their phone, enters the code under Join, and you're connected — same questions, live scores, head to head.

Have a friend's code?

Both devices need internet, and both should keep the game open on screen while you play. Set your display name in Profile first so your friend sees who's who. If a join can't find the room, the game keeps retrying on its own for a while — the most common cause is the host's room screen being closed or the app switched away.

🏆 How scoring works — QuizUp style

Every correct answer earns a base score plus a speed bonus. Answer instantly for the maximum. Wrong answers and timeouts score 0.
